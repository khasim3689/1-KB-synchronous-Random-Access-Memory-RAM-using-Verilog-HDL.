🚀 **Project Showcase: Design and Verification of a Fully Parameterized 1 KB Synchronous RAM Using Verilog HDL**

I’m excited to share my digital design project, implemented using **Verilog HDL and Xilinx Vivado**.

🔹 **Project Highlights**
- Designed a 1 KB synchronous RAM with a 256 × 32-bit memory organization.
- Implemented parameterized RTL for reusable memory design.
- Developed a Verilog testbench to verify read and write operations.
- Tested address selection, data readback, and boundary addresses.
- Explored behavioral simulation, waveform analysis, and FPGA memory inference.

💡 **Key Skills:** Verilog HDL | RTL Design | Functional Verification | Digital Design | Xilinx Vivado | Testbench Development

This project has helped me strengthen my understanding of synchronous memory architecture and simulation-based verification as I continue developing my skills in **VLSI design and RTL engineering**.
